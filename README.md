# Plataforma de Escuela de Música

Sitio web desarrollado como proyecto académico para una escuela de música. La plataforma permite a los estudiantes consultar y entregar tareas, además de registrar su tiempo de práctica.

El proyecto fue realizado durante mi segundo año de la carrera de **Ingeniería en Sistemas Computacionales**.

## Características

-  Registro e inicio de sesión de usuarios.
-  Consulta y entrega de tareas.
-  Registro del tiempo de práctica.
-  Consulta del tiempo de práctica registrado.
-  Gestión de información relacionada con las actividades musicales.
-  Conexión con una base de datos MySQL.

##  Tecnologías utilizadas

- **HTML**
- **CSS**
- **JavaScript**
- **PHP**
- **MySQL**
- **Bootstrap**

##  Plantilla

Para el diseño visual del sitio se utilizó una plantilla como base, realizando modificaciones y adaptaciones para ajustarla a las necesidades del proyecto académico.

La funcionalidad del sistema, integración con PHP y conexión con la base de datos fueron desarrolladas como parte del proyecto.

##  Base de datos

El proyecto utiliza **MySQL** para almacenar la información del sistema.

Por seguridad, el archivo que contiene las credenciales de conexión (`bd.php`) **no se encuentra incluido en el repositorio**.

Para utilizar el proyecto localmente:

1. Crear una base de datos llamada `proyecto`.
2. Importar el archivo SQL de la base de datos, si está disponible.
3. Crear el archivo `bd.php` a partir de `bd.example.php`.
4. Configurar las credenciales de MySQL.
5. Colocar el proyecto en un servidor local como **XAMPP**.
6. Abrir el proyecto desde el navegador.

## Ejecución local

Si utilizas XAMPP:

1. Copia el proyecto dentro de:

```text
C:\xampp\htdocs\
```

2. Inicia **Apache** y **MySQL** desde XAMPP.
3. Configura la base de datos en phpMyAdmin.
4. Configura `bd.php`.
5. Abre en el navegador:

```text
http://localhost/nombre-del-proyecto/
```
 Objetivo

El objetivo del proyecto fue desarrollar una plataforma web que permitiera llevar un mejor control de las actividades de los estudiantes de una escuela de música, principalmente la entrega de tareas y el registro de sus sesiones de práctica.

También fue una oportunidad para aplicar conocimientos de desarrollo web, programación con PHP, manejo de bases de datos y diseño de interfaces.
